07 How a session flows

Walk-in to
logout.

Five steps, no spreadsheet. Each one is logged, priced and synced to the Live Floor as it happens.

Check in

Walk-in, booking or app. Top up the wallet or sell a time package at the desk.

Unlock

The customer signs in at the PC with a password or PIN, or staff start it from the Live Floor.

Play

Games launch from the Shell; food ordered from the seat goes straight to the kitchen display.

Extend

Warnings at 30, 15, 10, 5 and 1 minute. Extend from the seat, the desk or the app.

Settle

One combined bill. Unused prepaid time is refunded and loyalty points land instantly.

08 Built like infrastructure

Keeps running
when the internet doesn't.

Cloud plus a branch edge server, so the floor keeps working through outages and syncs back afterwards.

Three-layer isolation

Row-level security in the database, a tenant-scoped client and route authorization, each tested in CI.

Signed commands

Per-branch keys sign every device command. PCs verify each one and reject replays.

Offline edge

A branch edge server keeps sessions, POS and the Shell working through outages, then syncs.

Tamper-evident audit

Append-only ledgers and a hash-chained audit log. Super Admin sign-in needs two-step verification.
