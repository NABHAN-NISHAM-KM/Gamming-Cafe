Install guide

Host once. Install on every PC.

Put the ArenaOS server online one time, then run ArenaOS-Station-Setup.exe on each gaming PC. Type an enrolment code and the PC appears on your Live Floor.

How it fits together

There are only two pieces. You host the server one time. Every gaming PC gets the station installer, which connects it to that server.

☁ Your server (host once)

  • Admin — admin.yourvenue.com
  • API + customer app — api.yourvenue.com
  • Database (PostgreSQL) + Redis
⇄
HTTPS + WebSocket

🖥 Each gaming PC

  • ArenaOS-Station-Setup.exe
  • Station agent (Windows service)
  • Gaming Shell (full-screen lock screen)

Gaming PCs only need to reach https://api.yourvenue.com. Staff use the admin in any browser, from anywhere.

1

Host the server (one time)

Use any VPS or cloud machine: DigitalOcean, Hetzner, AWS Lightsail, Azure and so on.

ItemMinimum
ServerUbuntu 22.04/24.04, 2 vCPU, 4 GB RAM, 40 GB SSD (4 vCPU / 8 GB for 100+ stations)
SoftwareNode.js 22+, Docker, Git, Caddy (for HTTPS)
DomainTwo DNS records pointing at the server's IP: admin and api
Open portsOnly 80 and 443. Keep the database, Redis, 3000 and 4000 closed to the internet.

1.1 Install the software

sudo apt update && sudo apt install -y git curl
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash - && sudo apt install -y nodejs
curl -fsSL https://get.docker.com | sudo sh
sudo apt install -y caddy
sudo npm install -g pm2

1.2 Get the code, database and settings

git clone <your-repo-url> /srv/arena && cd /srv/arena
npm install
npm run codegen -w @arena/db
cp .env.example .env
Before the first start: change every *_dev password in infra/postgres/init/001_roles.sql, infra/docker-compose.yml and .env to long random ones. In docker-compose.yml, bind the ports to the server itself ("127.0.0.1:5432:5432", "127.0.0.1:6379:6379") so the database is never public.

Add these production settings to .env:

NODE_ENV=production
CORS_ORIGINS=https://admin.yourvenue.com,https://api.yourvenue.com
ARENA_API_URL=http://localhost:4000
docker compose -f infra/docker-compose.yml up -d
cd packages/db && npx prisma migrate deploy && cd ../..
npm run keys -w @arena/api        # signing & encryption keys → .env (back this file up!)
npm run seed -w @arena/api        # platform data + your organization
Until self-serve sign-up ships (roadmap Phase 12), organizations, branches and the first owner account are created by apps/api/scripts/seed.ts. Replace the demo organization, emails and password there with your venue's before you run it.

1.3 Start the API and admin (kept running by pm2)

npm run build -w @arena/admin
npm run build -w @arena/customer
pm2 start "npx tsx apps/api/src/main.ts" --name arena-api
pm2 start "npm run start -w @arena/admin" --name arena-admin
pm2 save && pm2 startup           # restart automatically after a reboot

1.4 Domain & HTTPS

Create DNS A records for admin.yourvenue.com and api.yourvenue.com pointing at the server's IP. Then replace /etc/caddy/Caddyfile with the following. Caddy gets HTTPS certificates automatically.

admin.yourvenue.com {
    reverse_proxy localhost:3000
}

api.yourvenue.com {
    # API, station WebSockets and health check
    @api path /v1/* /health
    handle @api {
        reverse_proxy localhost:4000
    }
    # Customer app (PWA) + TV station display on the same host
    handle {
        root * /srv/arena/apps/customer/dist
        try_files {path} /index.html
        file_server
    }
}
sudo systemctl reload caddy

1.5 Check it works

  • https://api.yourvenue.com/health answers ok.
  • https://admin.yourvenue.com shows the admin sign-in. Sign in with the owner account from your seed.
  • https://api.yourvenue.com/<your-org-slug> opens the customer app.

That's the whole server. You don't touch it again except for updates (git pull, migrate, pm2 restart all) and backups of the database and .env.

2

Build the station installer (one time)

On any Windows PC with Node.js 22+, the .NET 8 SDK and Inno Setup 6, from the repository folder:

winget install JRSoftware.InnoSetup
.\clients\windows\package.ps1 -Installer -ApiUrl https://api.yourvenue.com

This creates one file, clients\windows\dist\installer\ArenaOS-Station-Setup.exe. It's self-contained, so gaming PCs don't need .NET. Your server address is pre-filled in the wizard, so staff only type the enrolment code.

ArenaOS-Station-Setup.exe

3

Install on every gaming PC

3.1 Prepare the PC

  • Windows 10 (version 2004 or newer) or Windows 11, 64-bit, fully updated.
  • Internet access to api.yourvenue.com. Wired Ethernet is recommended.
  • Microsoft Edge WebView2 Runtime. Windows 11 already has it; on Windows 10, install the Evergreen runtime. The installer warns you if it's missing.
  • A standard (non-administrator) Windows account for players, for example Player. Keep your own admin account for maintenance.
  • Power options: sleep Never. For Wake-on-LAN, enable it in the BIOS and on the network adapter, and turn off Fast Startup.

3.2 Create an enrolment code in the admin

  1. Sign in at https://admin.yourvenue.com.
  2. Go to Computers → Add stations.
  3. Pick the zone (for example Regular PCs), enter how many PCs you're adding, and choose how long the code is valid.
  4. Copy the code ARENA-XXXXX-XXXXX-XXXXX-XXXXX. It's shown only once. One code covers all the PCs you asked for.

3.3 Run the installer

Sign in to the PC with an administrator account and double-click ArenaOS-Station-Setup.exe.

  • If the address or code is wrong, the installer tells you on the spot and lets you type a new one. Nothing needs to be restarted.
  • Test mode (checkbox) only simulates restart, shutdown and lock, and doesn't start the Shell automatically. Use it on your first PC if you want to try things safely. Turn it off later with "C:\Program Files\ArenaOS\Agent\ArenaAgent.exe" safe-mode off and then restart the ArenaAgent service.

3.4 Check it on the Live Floor

  1. In the admin, open Live Floor. The new PC shows green (Available).
  2. Click it. CPU, GPU and RAM readings move, and hardware and peripherals are listed.
  3. Try Send message. The text pops up on the PC.
  4. Sign out of Windows and sign in as Player. The Gaming Shell opens full-screen on its lock screen. Start a session from the Live Floor, or let a customer sign in with their username and PIN.

Repeat 3.3 on every PC. Drag the stations into place with Live Floor → Edit layout.

Installing on many PCs at once

The installer runs unattended. That's handy with a deployment tool, a startup script, or a diskless image. Run it as Administrator:

ArenaOS-Station-Setup.exe /VERYSILENT /API=https://api.yourvenue.com /CODE=ARENA-XXXXX-XXXXX-XXXXX-XXXXX
OptionWhat it does
/API=Server address (not needed if it was built in with -ApiUrl)
/CODE=Enrolment code (required for a first install)
/NAME=PC-17Station name. Leave it out to number stations automatically.
/SAFEMODE=onInstall in test mode
/LOG="C:\arena-setup.log"Write a detailed setup log

Updating & uninstalling

  • Update: build a new installer and run it on the PC. It detects that the PC is already connected and offers Update the software only. The station keeps its name, history and connection, and no code is needed.
  • Move a PC to another venue: run the installer and choose Connect it again with a new enrolment code.
  • Uninstall: Windows Settings → Apps → ArenaOS Station → Uninstall. You'll be asked whether to also forget the PC's connection; answer No if you'll reinstall it as the same station. Retire it in the admin under Computers.

Alternative: server inside the venue

You can also run the server on a PC in the venue, with no domain needed. Give that PC a fixed IP (for example 192.168.1.10), open ports 3000 and 4000 in its firewall on the Private network, and build the installer with -ApiUrl http://192.168.1.10:4000. Staff open the admin at http://192.168.1.10:3000. The full step-by-step is in docs/16-test-guide.md.

With this setup the admin can only be reached inside the venue unless you add a VPN or tunnel. Hosting online (step 1) lets owners check every branch from anywhere.

Troubleshooting

ProblemFix
“Can't reach …/health”Open that address in a browser on the gaming PC. If it fails, check DNS, the Caddyfile, the server firewall (80/443) and that pm2 status shows arena-api online.
“Enrolment code is invalid, expired…”The code expired or its PC count ran out. Create a new one in Computers → Add stations.
“Your plan's station limit is reached”Retire unused stations or move to a bigger plan.
The PC stays grey (offline)In PowerShell, Get-Service ArenaAgent should say Running. Check Event Viewer → Application → ArenaAgent for errors.
The Gaming Shell doesn't openMake sure the player account is not an administrator, test mode is off, and the WebView2 Runtime is installed.
Wake-on-LAN doesn't workAt least one other station on the same network must be online. Also enable WOL in the BIOS and on the network adapter, and turn off Fast Startup.
